OZON 本地选品工作台 v5-priceui

使用方式：
1. 解压后双击 index.html 打开。
2. 点击或拖入 Excel/CSV/TSV 表格导入数据。
3. 可在左侧配置筛选、汇率、商品卡字段显示与排序，并可导入/导出控制台配置。

本版本优化：
- 商品卡卢布价格后显示原价划线价；价格区下方增加分割线。
- 人民币价格字号调整为 16px。
- 右上角排序、卡片/表格切换控件美化。
- 商品创建时间仅显示“已创建 X 天”。
- 跟卖最低/最高价显示为“低价~ 高价”。


本版更新：
1. 搜索/筛选中的“周转动态包含”已改为“最低周转动态”，按数值下限筛选。
2. 已包含默认配置文件 ozon_console_config.json；页面启动时会先加载内置默认配置，并尝试读取同目录配置文件覆盖默认值。
3. 如果浏览器因 file:// 限制无法自动读取同目录 JSON，可手动点击“读取配置”。
